Como usar o TO DO LIST

Tela inicial

  • A saudação exibida no topo é ajustada automaticamente de acordo com o horário do seu dispositivo (bom dia, boa tarde ou boa noite).
  • O mini calendário apresenta o mês atual: cada dia é colorido conforme o desempenho registrado naquela data. A legenda de cores correspondente está logo abaixo.
  • Selecione o botão COMEÇAR para acessar a lista de tarefas do dia.

Adicionando e completando tarefas

  • Digite a tarefa desejada no campo de texto e pressione Enter ou selecione o botão + para incluí-la na lista.
  • É possível planejar até 7 tarefas por dia.
  • Selecione o texto de uma tarefa para marcá-la (ou desmarcá-la) como concluída; tarefas concluídas são exibidas com um traço sobre o texto.
  • Utilize o botão editar para corrigir o texto de uma tarefa. Pressione Enter para confirmar a alteração ou Esc para cancelá-la.

Progresso e finalização do dia

  • A barra de progresso indica o percentual de tarefas concluídas até o momento.
  • O botão FINALIZAR DIA deve ser utilizado somente quando o dia estiver de fato encerrado: essa ação registra o resultado no histórico, atualiza o calendário e altera o HP do personagem. Não é possível finalizar o mesmo dia mais de uma vez com resultados distintos.

Seu personagem

O personagem representa a consistência do usuário ao longo do tempo, ganhando ou perdendo HP (em uma escala de 0 a 100) de acordo com o desempenho de cada dia finalizado.

Caso o HP atinja 0, o personagem é considerado derrotado. Para recuperá-lo, é necessário concluir 3 tarefas (em qualquer dia subsequente), retornando com uma quantidade inicial de HP. A derrota não resulta na perda do histórico ou do calendário já registrados.

Calendário de consistência

Cada dia do calendário recebe uma cor de acordo com o percentual de tarefas concluídas naquela data:

🟢 80–100% — Excelente 🟡 60–79% — Consistente 🟠 40–59% — Baixo 🔴 0–39% — Muito baixo ⚪ Dia sem uso registrado do site

Posicione o cursor sobre um dia colorido para visualizar o número de tarefas concluídas naquela data.

Sobre os seus dados

  • Todas as informações (tarefas do dia, histórico e personagem) são armazenadas localmente no navegador utilizado — não há criação de conta nem autenticação.
  • Os dados não são sincronizados entre dispositivos diferentes; cada navegador ou aparelho mantém seu próprio histórico de forma independente.
  • A exclusão dos dados de navegação do navegador resultará na perda do progresso registrado.
