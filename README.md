# 📝 To-Do List

Uma aplicação web de lista de tarefas desenvolvida para praticar **HTML, CSS e JavaScript**, com foco na criação de uma interface simples, organizada e interativa.

O projeto foi desenvolvido como parte do meu processo de aprendizado em desenvolvimento web, colocando em prática conceitos de estruturação de páginas, estilização e manipulação de elementos com JavaScript.

## 🚀 Demonstração

Acesse o projeto diretamente pelo GitHub Pages:

**[To-Do List](https://art1meireles.github.io/To-do-list/)**

## 📌 Sobre o projeto

O projeto apresenta uma interface de lista de tarefas com diferentes etapas de interação.

A aplicação possui uma tela inicial, uma área principal para utilização da lista e uma tela de finalização, criando uma experiência simples de navegação entre as etapas.

Além da funcionalidade, o projeto também busca trabalhar aspectos visuais como:

* Organização dos elementos na página
* Responsividade da interface
* Botões e elementos interativos
* Animações e transições
* Organização visual das tarefas

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura das páginas
* **CSS3** — estilização, layout e animações
* **JavaScript** — interatividade e lógica da aplicação

### 📄 Principais arquivos

**`index.html`**
Página inicial da aplicação.

**`index.js`**
Responsável pelas interações da página inicial.

**`dashboard.html`**
Página principal da aplicação, onde ocorre a interação com a lista de tarefas.

**`dashboard.js`**
Contém a lógica e as interações relacionadas ao dashboard.

**`finish.html`**
Página apresentada ao final do fluxo da aplicação.

**`finish.js`**
Responsável pelas interações da página de finalização.

**`style.css`**
Arquivo responsável pela estilização e organização visual da aplicação.

**`assets/`**
Pasta destinada aos recursos utilizados pelo projeto, como imagens.
